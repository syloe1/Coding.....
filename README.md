# CodeAlgorithm · 每日力扣

> 每天一道力扣题，按 **年 / 月 / 周** 归档，每周一个文件夹、七个文件，七天不中断。
> 目标：把刷题过程沉淀成可复习、可面试、可展示的结构化笔记。

---

## 📂 目录结构

```
CodeAlgorithm/
├── README.md                 # 本文件
├── TEMPLATE.md               # 单题笔记模板
├── 2026/                     # 按年
│   └── 11_Nov/               # 按月
│       └── W45_1102-1108/    # 按周（周一 ~ 周日）
│           ├── Day1_1102_1_两数之和.md
│           ├── Day2_1103_206_反转链表.md
│           ├── ...
│           └── Day7_1108_70_爬楼梯.md
```

**命名规则**

| 层级 | 格式 | 示例 |
|---|---|---|
| 年文件夹 | `YYYY/` | `2026/` |
| 月文件夹 | `MM_Mon/`（英文缩写） | `11_Nov/` |
| 周文件夹 | `Wxx_MMDD-MMDD/`（周一日期~周日日期） | `W45_1102-1108/` |
| 题文件 | `Day{1-7}_{MMDD}_{题号}_{题目名}.md` | `Day1_1102_1_两数之和.md` |

> Day1=周一，Day7=周日，和周文件夹里的日期一一对应。

## 🧩 每题笔记包含什么

每题统一用 [`TEMPLATE.md`](./TEMPLATE.md)，固定包含：

1. 题目元信息（题号 / 难度 / 标签 / 链接）
2. 题目大意一句话
3. 思路拆解（暴力 → 优化，带表格对比）
4. Go 代码（去注释纯净版 + 关键行注释版）
5. C++ 代码（跨语言对照）
6. 复杂度分析表
7. 面试坑点 & 变形追问
8. 自测三道小题

---

## 🎯 选题策略

- **周一~周五**：力扣每日一题 + Hot 100 里按专题推进
- **周六**：本周错题重做 / 同类题巩固
- **周日**：周总结 + 一道中等难度综合题

专题轮动顺序：数组 → 哈希 → 双指针 → 滑动窗口 → 链表 → 栈队列 → 二分 → 二叉树 → 回溯 → DP → 贪心 → 图论 → 设计题。
